# 中古車BPO 収益・投資シミュレーター

アッタデザインと管理パートナーNaSの店舗別収益、追加出店時の初期投資、NaSの月次用具費、一括／段階展開のキャッシュフローを確認する管理ダッシュボードです。

## 主な機能

- 対象6店舗のアッタ売上・直接原価・直接粗利
- NaS管理3店舗（草加・大宮・つくば）の受取額・スタッフ支払・直接粗利・用具費控除後利益
- LIVE COLOR管理1店舗（新狭山）の管理委託費
- 新狭山のLIVE COLOR委託単価は仕上げ5,500円（税込）／台、リチェック2,500円／台
- 新狭山は水洗い業務なし
- つくば研究学園店は展示在庫150台、当面は撮影業務なし
- 店舗別の処理台数、粗利率、スターターキット導入・回収状況
- 平均150台規模の追加店舗シミュレーション（1、3、5、7、10店舗／任意入力）
- スターターキット60万円／新規店舗の初期投資と回収月数
- NaS用具費3万円／管理店舗・月の継続費用
- 12、24、36か月の月次キャッシュフロー
- 一括展開と3か月ごとの段階展開の比較
- 税込／税抜、リチェック換算率、単価、台数、枠数、スタッフ数の変更
- スターターキットの一括・12・24・36か月按分表示

## ローカル起動

Node.js 22.13以上を使用します。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## 計算ロジック

計算は `lib/calculations.ts` の純粋関数へ集約しています。UIから分離されているため、将来データベースへ移行しても同じ計算を再利用できます。

### リチェック＋登録売上

実台数を枠数で均等配分し、各枠で換算率を掛けてから契約レンジを適用します。

- 100換算台未満: `370,000 - (100 - 換算台数) × 3,083.333`
- 100〜140換算台: `370,000`
- 140換算台超: `370,000 + (換算台数 - 140) × 3,083.333`

### アッタデザイン

- 直接粗利 = ガリバー売上 − 管理パートナーまたは直接スタッフへの支払い
- 初年度キャッシュ利益 = 年間直接粗利 − 新規店舗数 × スターターキット単価
- 投資回収月数 = 1店舗当たりスターターキット単価 ÷ 1店舗当たり月間直接粗利

既存店のスターターキットは支出済みとして将来追加投資から除外します。キャッシュフローでは、会計表示方法にかかわらず開設月に全額を支出します。

### NaS

- 直接粗利 = アッタからの受取額 − スタッフ支払額
- 用具費控除後利益 = 直接粗利 − 管理店舗数 × 月次用具費単価
- 用具費控除後利益率 = 用具費控除後利益 ÷ アッタからの受取額

NaS管理対象は草加インター店、WOW!TOWN大宮店、ガリバーつくば研究学園店です。新狭山店はLIVE COLOR管理、八王子みなみ野店と一宮店はアッタデザイン直接運営です。

## データ構成

- `lib/data.ts`: 店舗、単価、初期設定
- `lib/types.ts`: 将来DB化を見据えた型定義
- `lib/calculations.ts`: 純粋な計算関数
- `app/dashboard.tsx`: 画面と操作
- `tests/calculations.test.mjs`: 数値境界テスト
- `tests/rendered-html.test.mjs`: サーバー描画テスト
- `docs/database-design.md`: 将来DB化メモ

## モデル範囲

本モデルは直接粗利と、指定されたスターターキット・NaS用具費を控除した営業貢献利益までを扱います。本部人件費、採用費、交通費、保険、欠員補填、税務上の減価償却などは含みません。
